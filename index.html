Recall Privacy Policy

Last updated: October 6, 2026

Recall is a Chrome extension that lets users capture screenshots from webpages and save them with contextual information for later reference.

Data Stored by Recall

Recall may store screenshots, webpage URLs, page titles, domains, timestamps, notes, tags, and collections created by the user.

How Data Is Stored

Recall stores this information locally on the user's device using browser storage. Recall does not require an account or use a remote server to store user data.

Data Sharing

Recall does not sell, share, or transfer user data to third parties.

Data Collection

Recall does not use analytics, advertising trackers, or external services to collect user data.

Data Deletion

Users can delete saved memories directly within Recall.
